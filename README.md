# Shamiha Birthday Surprise

A personalized bilingual (Bangla + English) birthday microsite built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the project folder.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server (recommended), or open it directly in a modern browser.

## Interactions
- Click **A letter for my Bou** to open the 3D birthday letter.
- Tap the front cover of the letter to reveal the typewriter message.
- Click any gift box for a little personal surprise.
- Click a gallery photo to view it larger.
- Click the cake for the fullscreen birthday celebration.

## Customize
- Replace photos inside `assets/images/` and update the corresponding paths in `index.html`.
- Edit the bilingual letter in `js/letter.js`.
- Edit the three gift messages in `js/main.js`.
- Main colors and layout are defined in `css/style.css`.

The confetti effect uses the Canvas Confetti CDN. Google Fonts are also loaded online; the site remains usable if these external resources are unavailable.
